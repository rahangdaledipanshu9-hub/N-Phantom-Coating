## 🚀 Deployment Guide

### Option 1: Open Locally
```bash
# Windows
start index-luxury.html

# macOS
open index-luxury.html

# Linux
xdg-open index-luxury.html
```

### Option 2: GitHub Pages
1. Push `index-luxury.html` to your GitHub repo
2. Rename to `index.html`
3. Go to Settings > Pages
4. Select main branch
5. Your site is live at: `https://username.github.io/N-Phantom-Coating/`

### Option 3: Netlify (Easiest)
1. Go to [netlify.com](https://netlify.com)
2. Drag and drop `index-luxury.html`
3. Get instant free hosting
4. Custom domain available

### Option 4: Vercel (React)
```bash
# For the React component
npm create vite@latest my-app -- --template react
# Copy NPhantomLanding.jsx to src/
# Deploy: vercel deploy
```

### Option 5: Traditional Server
```bash
scp index-luxury.html user@yourserver:/var/www/html/
# Access at: http://yourdomain.com/index-luxury.html
```
